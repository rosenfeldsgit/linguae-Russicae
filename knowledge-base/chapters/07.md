# Задание 7. Образование форм слов

## Что проверяется
Нужно найти ошибочную форму слова и записать нормативную. Проверяются существительные, прилагательные, наречия, числительные, местоимения и глаголы. Ниже собраны правила образования форм, словарные формы для заучивания и полные образцы склонения.

## Правила
### R07-01. Существительные: формы, которые нужно выучить
**Правило.** Существительные одного рода и склонения могут иметь разные окончания множественного числа. В таблицах приведены нормативные формы для запоминания. Окончание по одному созвучному слову не выбирают.

**Именительный падеж множественного числа.**
| Запомнить окончание -ы / -и | Запомнить окончание -а / -я |
| --- | --- |
| бухгалтеры, инженеры, конструкторы | директора, профессора, доктора |
| договоры, приговоры, выговоры | паспорта, адреса, округа |
| лекторы, редакторы, корректоры | инспектора, сторожа, повара |
| тренеры, инструкторы, шофёры | мастера, катера, якоря |
| офицеры, диспетчеры, аптекари | берега, города, вечера |
| торты, банты, шарфы | купола, колокола, голоса |
| кремы, супы, соусы | сорта, борта, номера |
| фронты, порты, склады | поезда, острова, рукава |
| возрасты, выборы, почерки | отпуска, векселя, ордера |
| слесари, токари, столяры | глаза, рога, края |

**Форма зависит от значения.**
| Значение | Форма | Другое значение и форма |
| --- | --- | --- |
| Часть книги, бумаги | листы | Части растения — листья |
| Документ для входа | пропуска | Отсутствие, пробелы в тексте — пропуски |
| Цветовой оттенок | тона | Звуки, особенности речи — тоны |
| Религиозное изображение | образа | Художественные изображения, типы — образы |
| Награды | ордена | Объединения — ордены |

**Родительный падеж множественного числа — без окончания.**
| Группа | Формы для заучивания |
| --- | --- |
| Парные предметы | нет сапог, ботинок, валенок, чулок, погон, эполет |
| Народы и военные | армян, грузин, башкир, татар, туркмен, осетин; солдат, партизан |
| Плоды | яблок, слив, груш, вишен, черешен, дынь |
| На -ня | башен, вишен, боен; деревень, кухонь, спален |
| На -ля | туфель, петель, капель, сабель |
| На -це | блюдец, зеркалец, полотенец |
| Другие трудные формы | мест, дел, колец, сердец, плеч, туч, рощ, вафель, басен, барж, макарон |

**Родительный падеж множественного числа — с окончанием.**
| Окончание | Формы для заучивания |
| --- | --- |
| -ов | носков, гольфов, джинсов, рельсов |
| -ов | помидоров, огурцов, баклажанов, апельсинов, мандаринов, лимонов, абрикосов |
| -ов | узбеков, якутов, монголов, эскимосов |
| -ев | платьев, устьев, братьев, верховьев, лохмотьев |
| -ей | сыновей, свечей, простыней, граблей, яслей, будней, долей |

**Варианты.** Нормативны «простыней / простынь», «граблей / грабель». В обычном сочетании «нет свечей», в устойчивом «игра стоит свеч». «Сумерек» имеет нулевое окончание, «будней» — окончание -ей.

**Единицы измерения.** В счётных сочетаниях употребляются «пять ампер», «десять вольт», «сто ватт», «двести граммов» и «двести грамм», «пять килограммов» и «пять килограмм». Варианты «грамм» и «килограмм» допустимы при числительном. Формы «метров», «сантиметров», «гектаров» сохраняют -ов.

### R07-08. Род существительных и несклоняемые слова
**Правило.** У несклоняемых географических названий род устанавливают по родовому понятию; у несклоняемых аббревиатур — по главному слову полного названия. Род общеупотребительных несклоняемых слов запоминают по словарю.

| Мужской род | Женский род | Средний род |
| --- | --- | --- |
| кофе, тюль, шампунь | мозоль, вуаль, бандероль | какао, пальто, пианино |
| рояль, рельс, аэрозоль | авеню, салями, кольраби | метро, такси, жюри |
| Сочи — город | Миссисипи — река | Онтарио — озеро |
| МГУ — университет | ООН — организация | — |

**Запомни.** Кофе в нейтральной литературной речи — мужского рода. У «кофе» средний род имеет разговорную помету. «Тюль» — мужского рода: «белый тюль». Сокращения, ставшие обычными склоняемыми словами, получают род по форме: «вуз открылся».

### R07-19. Особые формы существительных единственного числа
**Правило.** Разносклоняемые существительные на -мя в косвенных падежах получают -ен-; у «время» и «семя» во множественном числе есть особые формы. Формы «кочерёг» и «доньев» запоминают по словарю.

| Исходная форма | Нормативная форма |
| --- | --- |
| время | нет времени; много времён |
| семя | нет семени; много семян |
| имя | нет имени; много имён |
| знамя | нет знамени; много знамён |
| стремя | нет стремени; много стремян |
| кочерга | несколько кочерёг |
| дно | несколько доньев |
| полотенце | несколько полотенец |
| простыня | несколько простыней |
| яблоня | несколько яблонь |

### R07-02. Степени сравнения прилагательных и наречий
**Правило.** Для одной степени сравнения выбирают одну модель. Простую сравнительную степень образуют суффиксы -ее / -ей, -е, -ше; составную — слова «более» или «менее» и исходная форма.

| Степень | Простая форма | Составная форма |
| --- | --- | --- |
| Сравнительная прилагательного | умнее, выше, тоньше | более умный, менее высокий |
| Превосходная прилагательного | умнейший, высочайший | самый умный, наиболее высокий |
| Сравнительная наречия | говорить громче | говорить более громко |
| Превосходная наречия | — | говорить громче всех, наиболее громко |

**Запомни особые формы.** Хороший / хорошо → лучше; плохой / плохо → хуже; маленький / мало → меньше; большой / много → больше.

**Недопустимое смешение.** «Более красивее» исправляют на «красивее» или «более красивый», «самый красивейший» — на «самый красивый» или «красивейший». Литературная форма — «красивее», разговорное «красивше» для экзамена не подходит.

### R07-05. Местоимения и формы после предлогов
**Правило.** Притяжательные «его», «её», «их» не изменяются. У личных местоимений 3-го лица после большинства простых предлогов появляется начальное н.

| Значение / условие | Нормативно | Почему |
| --- | --- | --- |
| Принадлежность | их учебники, её пальто, его письмо | Притяжательная форма неизменяема |
| Лицо после предлога | у него, к ней, с ними, между ними | Начальное н у личного местоимения |
| Предлог относится к существительному | у его брата, к её дому | «Его», «её» обозначают принадлежность |
| Производный предлог с дательным падежом | благодаря ему, вопреки ей, согласно им | В этих сочетаниях н не добавляется |
| Сравнительная степень | старше его, выше её | Сравнительная форма не требует н |
| Возвратное местоимение | к себе, перед собой | «Себя» не имеет именительного падежа |

**Запомни.** «Ихний», «ейный», «евонный» заменяют на «их», «её», «его».

### R07-04. Глагольные формы для заучивания
**Правило.** Повелительное наклонение выражает просьбу или приказ. Личные формы называют действие лица. Для глаголов с чередованием и особыми основами нормативную форму запоминают целиком.

| Инфинитив | Повелительная форма | Форма настоящего / будущего времени |
| --- | --- | --- |
| класть | клади, кладите | кладёт, кладут |
| положить | положи, положите | положит, положат |
| лечь | ляг, лягте | ляжет, лягут |
| ехать | поезжай, поезжайте | едет, едут |
| ездить | езди, ездите | ездит, ездят |
| бежать | беги, бегите | бежит, бегут |
| хотеть | — | хочет, хотят |
| печь | пеки, пеките | печёт, пекут |
| беречь | береги, берегите | бережёт, берегут |
| жечь | жги, жгите | жжёт, жгут |
| стереть | сотри, сотрите | сотрёт, сотрут |
| махать | маши, машите | машет, машут |

**Запомни.** Нет нормативных форм «ложи», «ляжь», «ехай», «езжай» для нейтрального экзаменационного ответа. Используй «клади», «ляг», «поезжай». У «победить», «убедить», «очутиться» избегают затруднительной формы 1-го лица единственного числа: «смогу победить», «постараюсь убедить», «окажусь».

**Прошедшее время.** Нормативны «сох», «мок», «замёрз», «исчез», «достиг», «привык». В женском роде: сохла, мокла, замёрзла, исчезла, достигла, привыкла.

### R07-20. Деепричастия и возвратные формы
**Правило.** Деепричастие несовершенного вида обозначает добавочное действие как процесс, совершенного — как завершённое действие. Форму образуют от соответствующей глагольной основы, сохраняя возвратность исходного действия.

| Инфинитив | Нормативное деепричастие |
| --- | --- |
| читать | читая |
| торопиться | торопясь |
| вернуться | вернувшись |
| прочитать | прочитав |
| лежать | лёжа |
| класть | кладя |
| идти | идя |
| быть | будучи |

**Запомни.** «Будучи», «идя», «кладя» — особые основы. От «ехать» употребляют описательный оборот «во время поездки» вместо искусственного «ехая».

### R07-03. Числительные: виды и главное правило склонения
**Правило.** Количественное числительное отвечает на вопрос «сколько?», порядковое — «который по счёту?». В составном количественном изменяются все слова, в составном порядковом — только последнее.

| Вид | Строение | Пример | Что изменяется |
| --- | --- | --- | --- |
| Количественное простое | Одно слово, одна основа | восемь | Всё числительное: восьми |
| Количественное сложное | Одно слово, две части | восемьсот | Обе части: восьми-сот |
| Количественное составное | Несколько слов | восемьсот восемь | Все слова: восьмисот восьми |
| Порядковое составное | Последнее слово называет порядок | восемьсот восьмой | Последнее слово: восемьсот восьмого |
| Дробное | Числитель и знаменатель | три пятых | Обе части: трёх пятых |
| Собирательное | Количество как группа | трое | Числительное: троих |

### R07-09. Падежи и полное склонение числа 8888
**Правило.** Падеж определяется связью с управляющим словом или предлогом. Вопрос задают ко всему количественному сочетанию, затем в этом падеже изменяют каждую его часть.

**Таблица падежей.**
| Падеж | Вопросы к существительному | Вопрос к количеству | Подсказка |
| --- | --- | --- | --- |
| Именительный | кто? что? | сколько? | есть |
| Родительный | кого? чего? | скольких? | нет, около |
| Дательный | кому? чему? | скольким? | дать, к |
| Винительный | кого? что? | сколько? скольких? | вижу, купить |
| Творительный | кем? чем? | сколькими? | доволен, с |
| Предложный | о ком? о чём? | о скольких? | говорить о |

**8888 рублей — по всем падежам.**
| Падеж | Полное сочетание |
| --- | --- |
| И. | восемь тысяч восемьсот восемьдесят восемь рублей |
| Р. | восьми тысяч восьмисот восьмидесяти восьми рублей |
| Д. | восьми тысячам восьмистам восьмидесяти восьми рублям |
| В. | восемь тысяч восемьсот восемьдесят восемь рублей |
| Т. | восемью тысячами восемьюстами восемьюдесятью восемью рублями |
| П. | о восьми тысячах восьмистах восьмидесяти восьми рублях |

**Как устроена творительная форма.** Восемь → восемью; тысяча → тысячами; восемьсот → восемьюстами; восемьдесят → восемьюдесятью; восемь → восемью. У восьми также нормативны формы с «восьмью»: восьмью, восьмьюстами, восьмьюдесятью.

Здесь винительный совпал с именительным: «купить 8888 рублей» — сумма названа как неодушевлённый объект. У числительных два, три, четыре с одушевлёнными существительными проверяй винительный отдельно: «вижу двух учеников», «вижу три стола».

### R07-11. Один, два, три, четыре — все падежи
**Правило.** «Один» согласуется с существительным в роде, числе и падеже. У «два» в именительном и винительном различаются «два» и «две». Остальные формы зависят от падежа.

| Падеж | Один — мужской род | Одна — женский род | Два / две | Три | Четыре |
| --- | --- | --- | --- | --- | --- |
| И. | один | одна | два / две | три | четыре |
| Р. | одного | одной | двух | трёх | четырёх |
| Д. | одному | одной | двум | трём | четырём |
| В. | один / одного | одну | два / две / двух | три / трёх | четыре / четырёх |
| Т. | одним | одной / одною | двумя | тремя | четырьмя |
| П. | об одном | об одной | о двух | о трёх | о четырёх |

**Средний род.** Одно — одного — одному — одно — одним — об одном. Множественное число «одни» имеет формы «одних», «одним», «одними»: «одни ножницы», «с одними ножницами».

**Винительный.** Вижу одного ученика, но один дом; двух учеников, но два дома; трёх учениц, но три книги; четырёх щенят, но четыре кресла.

### R07-12. От пяти до двадцати и тридцать
**Правило.** Числительные от пяти до двадцати и тридцать склоняются по одному типу. В родительном, дательном и предложном — окончание -и, в творительном — -ью. У «восемь» есть две нормативные творительные формы.

| Падеж | 5 | 8 | 11 | 20 | 30 |
| --- | --- | --- | --- | --- | --- |
| И. | пять | восемь | одиннадцать | двадцать | тридцать |
| Р. | пяти | восьми | одиннадцати | двадцати | тридцати |
| Д. | пяти | восьми | одиннадцати | двадцати | тридцати |
| В. | пять | восемь | одиннадцать | двадцать | тридцать |
| Т. | пятью | восемью / восьмью | одиннадцатью | двадцатью | тридцатью |
| П. | о пяти | о восьми | об одиннадцати | о двадцати | о тридцати |

### R07-13. Пятьдесят — восемьдесят: изменяются обе части
**Правило.** В числительных на -десят склоняются обе части: «пять» и «десят». В творительном первая часть имеет форму «пятью», «шестью», «семью», «восемью / восьмью», вторая — «десятью».

| Падеж | 50 | 60 | 70 | 80 |
| --- | --- | --- | --- | --- |
| И. | пятьдесят | шестьдесят | семьдесят | восемьдесят |
| Р. | пятидесяти | шестидесяти | семидесяти | восьмидесяти |
| Д. | пятидесяти | шестидесяти | семидесяти | восьмидесяти |
| В. | пятьдесят | шестьдесят | семьдесят | восемьдесят |
| Т. | пятьюдесятью | шестьюдесятью | семьюдесятью | восемьюдесятью / восьмьюдесятью |
| П. | о пятидесяти | о шестидесяти | о семидесяти | о восьмидесяти |

**Запомни.** «Пятьюдесятью» — творительный. Формы «пятидесятью», «шестидесятью», «семидесятью» ошибочны.

### R07-14. Двести — девятьсот: окончания сотен
**Правило.** В названиях сотен меняются обе части. В родительном вторая часть имеет форму -сот, в дательном -стам, в творительном -стами, в предложном -стах.

| Падеж | 200 | 300 | 400 | 500 |
| --- | --- | --- | --- | --- |
| И. | двести | триста | четыреста | пятьсот |
| Р. | двухсот | трёхсот | четырёхсот | пятисот |
| Д. | двумстам | трёмстам | четырёмстам | пятистам |
| В. | двести | триста | четыреста | пятьсот |
| Т. | двумястами | тремястами | четырьмястами | пятьюстами |
| П. | о двухстах | о трёхстах | о четырёхстах | о пятистах |

| Падеж | 600 | 700 | 800 | 900 |
| --- | --- | --- | --- | --- |
| И. | шестьсот | семьсот | восемьсот | девятьсот |
| Р. | шестисот | семисот | восьмисот | девятисот |
| Д. | шестистам | семистам | восьмистам | девятистам |
| В. | шестьсот | семьсот | восемьсот | девятьсот |
| Т. | шестьюстами | семьюстами | восемьюстами / восьмьюстами | девятьюстами |
| П. | о шестистах | о семистах | о восьмистах | о девятистах |

**Запомни.** Родительный «трёхсот», дательный «трёмстам», творительный «тремястами». Формы «трёхста», «трёхстам», «трёхстами» ошибочны.

### R07-10. Сорок, девяносто, сто, полтора и полтораста
**Правило.** У этих числительных две падежные формы: одна для именительного и винительного, другая — для всех остальных падежей. У «полтора» в именительном и винительном есть родовая пара «полторы».

| Падеж | 40 | 90 | 100 | 1,5 | 150 |
| --- | --- | --- | --- | --- | --- |
| И. | сорок | девяносто | сто | полтора / полторы | полтораста |
| Р. | сорока | девяноста | ста | полутора | полутораста |
| Д. | сорока | девяноста | ста | полутора | полутораста |
| В. | сорок | девяносто | сто | полтора / полторы | полтораста |
| Т. | сорока | девяноста | ста | полутора | полутораста |
| П. | о сорока | о девяноста | о ста | о полутора | о полутораста |

**Запомни.** Сорока рублями, девяноста метрами, ста страницами, полутора часами, полутора неделями, полутораста рублями. «Полтора» требует мужского или среднего рода («полтора часа», «полтора окна»), «полторы» — женского («полторы минуты»). В косвенных падежах существительное становится во множественное число.

### R07-15. Тысяча, миллион, миллиард
**Правило.** Эти названия количества имеют грамматические признаки существительного. «Тысяча» склоняется как существительное женского рода на -а, «миллион» и «миллиард» — как существительные мужского рода с нулевым окончанием.

| Падеж | 1000 | 2000 | 1 000 000 |
| --- | --- | --- | --- |
| И. | тысяча | две тысячи | миллион |
| Р. | тысячи | двух тысяч | миллиона |
| Д. | тысяче | двум тысячам | миллиону |
| В. | тысячу | две тысячи | миллион |
| Т. | тысячей / тысячью | двумя тысячами | миллионом |
| П. | о тысяче | о двух тысячах | о миллионе |

**Управление.** В сочетании с названием счётной единицы зависимое существительное стоит в родительном множественного: «к тысяче рублей», «с миллионом жителей». С формой «тысячью» возможно также согласование в творительном: «с тысячью рублями». В полном 8888 заключительное числительное определяет форму «рублей» в именительном, а в дательном согласуется с «рублям».

### R07-06. Оба и обе — все падежи
**Правило.** «Оба» сочетается с существительными мужского и среднего рода, «обе» — женского. Род сохраняется при склонении. У слова, имеющего только множественное число, род не определяется: вместо «обои сутки» говорят «двое суток».

| Падеж | Мужской / средний род | Женский род |
| --- | --- | --- |
| И. | оба ученика, оба окна | обе ученицы |
| Р. | обоих учеников, обоих окон | обеих учениц |
| Д. | обоим ученикам, обоим окнам | обеим ученицам |
| В. | обоих учеников; оба окна | обеих учениц; обе книги |
| Т. | обоими учениками, обоими окнами | обеими ученицами |
| П. | об обоих учениках, об обоих окнах | об обеих ученицах |

### R07-07. Собирательные числительные
**Правило.** Двое — десятеро называют количество как совокупность. Их сочетаемость ограничена лексическим значением и грамматической формой существительного.

| Можно употребить | Образец |
| --- | --- |
| Лица мужского пола и общего пола | двое друзей, трое сирот |
| Слова «дети», «ребята», «люди» | трое детей, двое ребят |
| Детёныши животных | двое котят, трое щенят |
| Личные местоимения | нас трое, их было двое |
| Слова только множественного числа | двое суток, трое ножниц |

**Ограничения.** С названиями лиц женского пола употребляют количественные: «две студентки». Со взрослыми животными — «два волка». В официально-деловой речи при названии должности предпочтительно «два профессора», «три генерала».

**Склонение.**
| Падеж | Двое | Трое |
| --- | --- | --- |
| И. | двое | трое |
| Р. | двоих | троих |
| Д. | двоим | троим |
| В. | двоих друзей; двое суток | троих друзей; трое суток |
| Т. | двоими | троими |
| П. | о двоих | о троих |

У существительных только множественного числа в косвенных падежах обычно переходят к количественному: «двумя ножницами», «о трёх сутках». Для 22 суток удобно «двадцать два дня» или «в течение двадцати двух суток».

### R07-16. Порядковые числительные и даты
**Правило.** Порядковое числительное изменяется как прилагательное. В составном порядковом изменяется только последнее слово. В обозначении даты название месяца ставят в родительном.

| Падеж | 8888-й участник |
| --- | --- |
| И. | восемь тысяч восемьсот восемьдесят восьмой участник |
| Р. | восемь тысяч восемьсот восемьдесят восьмого участника |
| Д. | восемь тысяч восемьсот восемьдесят восьмому участнику |
| В. | восемь тысяч восемьсот восемьдесят восьмого участника |
| Т. | восемь тысяч восемьсот восемьдесят восьмым участником |
| П. | о восемь тысяч восемьсот восемьдесят восьмом участнике |

**Год.** Две тысячи двадцать седьмой год → в две тысячи двадцать седьмом году → к две тысячи двадцать седьмому году. В варианте «к двум тысячам» склоняется количественное обозначение суммы, это другое сочетание.

**Дата.** Первое сентября; к первому сентября; с первым сентября. После «к» меняется «первое», а «сентября» сохраняется.

### R07-17. Дробные числительные и десятичные дроби
**Правило.** В обычной дроби числитель склоняется как количественное, знаменатель — как порядковое. Название измеряемого предмета после дроби имеет родительный единственного числа: «три пятых литра».

| Падеж | 3/5 литра |
| --- | --- |
| И. | три пятых литра |
| Р. | трёх пятых литра |
| Д. | трём пятым литра |
| В. | три пятых литра |
| Т. | тремя пятыми литра |
| П. | о трёх пятых литра |

**Десятичная дробь.** 2,5 метра читается «две целых пять десятых метра». В творительном — «двумя целыми пятью десятыми метра». После дробной части сохраняется «метра», даже если целая часть больше одного.

**Слово «половина».** Два с половиной часа, пять с половиной часов. Здесь форму существительного определяет целое число: два часа, пять часов. Для «полтора» действует отдельная таблица.

### R07-18. Числительное и существительное: согласование и управление
**Правило.** В именительном и совпадающем с ним винительном форма существительного зависит от последнего числового компонента. В косвенных падежах два и более требуют от существительного того же падежа во множественном числе.

| Последний компонент | Форма существительного | Сочетание |
| --- | --- | --- |
| Один, кроме 11 | Единственное число, согласование | двадцать один рубль |
| Два, три, четыре, кроме 12–14 | Родительный единственного | двадцать два рубля |
| Пять — девять, ноль; 11–14 | Родительный множественного | двадцать пять рублей, двенадцать рублей |
| Косвенный падеж | Тот же падеж, множественное число | к двадцати двум рублям, с двадцатью пятью рублями |

**Одушевлённость.** «Вижу двух друзей», но «вижу два дома». В составных сочетаниях на два, три, четыре нормативно «пригласить двадцать два участника». Не переноси автоматически форму простого числительного на составное.

## Как применять
1. Определи часть речи и требуемый падеж, число, род или наклонение.
2. Для словарной формы найди слово в таблице и запомни его целиком.
3. Для числительного установи вид: количественное, порядковое, дробное или собирательное.
4. Просклони каждую нужную часть и согласуй зависимое существительное.
5. В ответ запиши исправленную форму без добавленных пояснений.

## Разборы
- «К восьмиста рублям» → «к восьмистам рублям». Дательный падеж сложного числительного меняет обе части.
- «С обеими учениками» → «с обоими учениками». Мужской род требует основы обо-.
- «В двух тысячах двадцать седьмом году» → «в две тысячи двадцать седьмом году». Порядковое обозначение года изменяет только последнее слово.
- «Нет новых туфлей» → «нет новых туфель». Нормативную форму запоминают по таблице.
- «Более выше» → «выше» или «более высокий». Выбирается одна модель степени сравнения.

## Типичные ошибки
Выбирать окончание существительного по созвучию; менять только последнее слово количественного числительного; склонять все слова порядкового; писать -ста вместо -сот в родительном; образовывать «обеих» при существительном мужского рода; смешивать две степени сравнения.
