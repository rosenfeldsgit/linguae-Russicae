# Задание 5. Паронимы и лексическая сочетаемость

## Что проверяется
Различение похожих по звучанию слов с разными значениями и сочетаемостью. В полной экзаменационной форме нужно исправить неверно употреблённое слово, сохранив нужную грамматическую форму. В карточке сайта выбирается слово для одного контекста.

## Правила
### R05-01. Значение определяет выбор
**Правило.** Паронимы не взаимозаменяемы автоматически. Сначала назвать смысл предложения, затем проверить значение каждого кандидата.
**Пример.** Эффектный выход — производящий впечатление; эффективный способ — дающий результат. «Результативный метод» → эффективный.

### R05-02. Частые пары
| Пара | Различие и опорные сочетания |
| --- | --- |
| надеть / одеть | надеть что? пальто; одеть кого? ребёнка |
| представить / предоставить | представить доклад, познакомить; предоставить возможность, помещение |
| адресант / адресат | отправитель / получатель |
| абонент / абонемент | пользователь услуги / право или документ на регулярное посещение |
| оплатить / заплатить | оплатить проезд; заплатить за проезд |
| освоить / усвоить | освоить технику, территорию; усвоить правило, пищу |
| экономный / экономичный / экономический | бережливый человек / малозатратный двигатель / относящийся к экономике |
| дипломатический / дипломатичный | связанный с дипломатией / тактичный |
| артистический / артистичный | относящийся к искусству артиста / выразительный, обладающий артистизмом |
| доверительный / доверчивый | основанный на доверии / легко доверяющий |
| сытый / сытный | насытившийся человек / хорошо насыщающая еда |
| песчаный / песочный | содержащий песок, состоящий из него / относящийся к песку; также цвет, тесто |
| каменный / каменистый | сделанный из камня / изобилующий камнями |
| дождевой / дождливый | связанный с дождём / с частыми дождями |
| памятный / памятливый | сохраняющийся в памяти / обладающий хорошей памятью |
| охватить / обхватить | распространиться, овладеть чувством / окружить руками |

**Как отличить паронимы.**
| Пара | Сочетания |
| --- | --- |
| Освоить / усвоить | освоить станок — научиться работать; усвоить правило — понять и запомнить |
| Дипломатический / дипломатичный | дипломатическая миссия — сфера деятельности; дипломатичный ответ — тактичный |
| Представить / предоставить | представить расчёт — показать; предоставить отпуск — дать |

### R05-03. Однокоренные ряды длиннее пары
**Правило.** Ряд может содержать три и более слова. Сравнивать все значения, а не выбирать между двумя случайно оставленными вариантами.
**Примеры.** Экономный — экономичный — экономический; единичный — единственный — единый; гарантийный — гарантированный.
**Ловушка.** Гарантийный срок связан с гарантией; гарантированный доход обеспечен гарантией. Смысл близок, сочетаемость различается.

### R05-04. Грамматическая форма и управление
**Правило.** После выбора леммы восстановить род, число, падеж, время или лицо по предложению.
**Примеры.** Стал эффективным средством; предоставили возможность; заплатили за билет. Нельзя исправлять лексическую ошибку новой грамматической ошибкой.

### R05-05. Ассоциации
**Пример.** «Надеть одежду — одеть Надежду» помогает различить объект действия. После ассоциации всё равно проверить вопрос: что? или кого?
**Ловушка.** Не подгонять широкий контекст под один мнемонический пример: художественная метафора может расширять сочетаемость.

### R05-06. Словарные ряды проекта
В словнике этой главы собраны паронимы из тренировок. Сравни значения внутри ряда и придумай короткое словосочетание с каждым словом.

### R05-07. Предоставить и представить
Предоставить — дать возможность или право: предоставить отпуск, предоставить слово. Представить — показать, познакомить, вообразить: представить проект, представить гостя, представить картину. Смотри на объект действия.

### R05-08. Суффиксальные, приставочные и корневые паронимы
Суффиксы помогают различать «экономический» (относящийся к экономике) и «экономичный» (позволяющий экономить). У «вдохнуть» и «вздохнуть» различаются приставки и само действие. У созвучных «эскалатор» и «экскаватор» разные корни: первый перевозит пассажиров, второй копает грунт.

### R05-09. Что подсказывает значение морфемы
Суффикс -ист- может указывать на обилие признака: «каменистая тропа» усеяна камнями, «каменная лестница» сделана из камня. Приставки помогают различить направление действия: «выплатить премию» — выдать деньги, «доплатить за доставку» — внести дополнительную сумму. Проверяй догадку по значению всего слова.

### R05-10. Как читать суффиксы прилагательных
«Доверительный разговор» предполагает открытость собеседников, «доверчивый собеседник» легко верит людям. Суффикс -чив- помогает увидеть склонность человека. В другой паре «артистический коллектив» связан с артистами, а «артистичное исполнение» обнаруживает мастерство. Одному суффиксу нельзя приписать единственное значение для всех слов.

## Как применять
1. Найти слово, с которым сочетается выделенное.
2. Определить нужный смысл и часть речи.
3. Сравнить значения кандидатов, затем управление.
4. Вписать выбранное слово в правильной форме.

## Разборы
- «Разработан ___ способ очистки» → **эффективный**, потому что оценивается результат.
- «Он ___ ребёнка и ___ пальто» → **одел**, **надел**: разные объекты действия.
- «Гнев ___ его» → **охватил**: чувство овладело человеком, а не обняло руками.

## Типичные ошибки
Выбирать самое знакомое слово; игнорировать падеж; считать любую пару синонимами.
