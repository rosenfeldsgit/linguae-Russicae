# ege-russkiy

## Карточки

Файлы заданий находятся в [cards](cards/). Для правки Н и НН откройте [задание 15](cards/task-15.js) и найдите числовой id. Запишите слово целиком в word, верный вариант в answer, варианты кнопок в choices, правило в explanation. У старых карточек сохраняйте legacyId для связи с админкой. При включённой админке её опубликованные записи имеют приоритет.
