# Оформление Руса Лингво

Сайт использует плакатную типографику, тёплый бумажный фон, кобальтовые акценты и линейный растр.

Общие стили интерфейса находятся в `styles.css`, плакатная тема — в `poster.css`. `poster.js` управляет меню, предварительной загрузкой разделов и боковой подписью карточек. Стили разделов находятся рядом с их HTML.

Исходный редактируемый макет сохранён в Figma. Опубликованный интерфейс развивается в коде. [Макет](https://www.figma.com/design/e8jZCPKl7QCpLgjiBdYvwE).

## Ресурсы

Golos, Roboto Condensed и IBM Plex Mono загружаются локально в формате WOFF2. Исходные TTF нужны для воспроизводимой сборки `scripts/build_fonts.py`, лицензии OFL находятся в `assets/fonts/`.

Иконка сайта хранится в `favicon.svg`, плакатная иллюстрация — в `assets/brand-poster.svg`. Названия разделов выводятся текстом в HTML.

Палитра задана переменными в `poster.css`.

| Роль | Цвет |
| --- | --- |
| Фон | #F2F0E7 |
| Карточка | #FAF9F3 |
| Текст | #191A18 |
| Второстепенный | #62645E |
| Линии | #CDCEC4 |
| Кобальт | #293EF4 |
| Акцент | #FF4D25 |
| Подсветка пояснений карточек | #D7F481 |

Перед публикацией изменений оформления выполнить `node tests/browser.js`. Зависимости и команды установки указаны в корневом README.
