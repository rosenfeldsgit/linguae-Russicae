# Состояние проекта на 13.11.2026

## Сайт и данные

Статический интерфейс на HTML/CSS/JavaScript, публикация GitHub Pages в подкаталоге `/linguae-Russicae/`. В репозитории также есть Django-сервер и импорт статических данных. Наличие сервера в репозитории не означает, что он обслуживает опубликованный GitHub Pages.

Карточки находятся в `cards.js`, `adapted-cards.js`, `collection-cards.js`, `paronyms.js`, `punctuation.js`; часть заданий №1 и словник ударений находятся в `app.js`. Полные варианты — `test/bank.js` и JSON по сборникам. Они не являются нормативными справочниками.

## Учебные решения пользователя

Короткие карточки с выбором. История показывает все отвеченные карточки, верные и ошибочные; подсветка отражает результат. Информация по ответу доступна у обоих результатов. «Запомни» уместно для исключений/словарных форм; где есть правило или проверка, оно должно быть главным. Не повторять предложение целиком в подсказке.

Полная теория может включать порядок применения, но не должна состоять из общего алгоритма вместо конкретного знания. Ассоциации допускаются без искажения нормы.

## Что в этой ветке не делается

Не создаётся маршрут теории, не меняется внешний вид, не публикуются автоматически документы из этой папки, не меняются тренировочные ключи и настройки веток GitHub. Это контентная поставка для следующего этапа.

## Неодинаковая проверенность старых данных

Проект содержит старые общие и автоматически составленные объяснения, в том числе в коллекциях. Их экспорт нужен для поиска нужных ID и сопоставления, но не делает их научно проверенными. При расхождении выбирать правило из главы и нормативный источник; не «исправлять» главу под сомнительную старую подсказку.
