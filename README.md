# Русский

Карточки, пробники и база знаний для подготовки к ЕГЭ по русскому языку.

Действующий сайт — https://rosenfeldsgit.github.io/linguae-Russicae/.

## Структура

| Путь | Содержимое |
| --- | --- |
| `cards/task-*.js` | Карточки каждого задания вместе с ответами и объяснениями |
| `cards/catalog.js` | Преобразование записей в формат тренажёра |
| `app.js` | Выбор карточек, проверка ответа и история |
| `test/` | Полные задания пробников, тексты, ключи и интерфейс |
| `exam-explanations.js` | Дополнительные разборы отдельных заданий пробников |
| `knowledge-base/chapters/` | Учебные главы с постоянными ID правил |
| `theory/` | Собранная страница базы знаний |
| `assets/` | Локальные шрифты, изображения и иконки |
| `scripts/` | Сборка сайта, генерация паронимов и проверка секретов |
| `data/` | Исходные материалы и исключённые контексты паронимов |
| `server/` | Django-админка и конфигурация серверного размещения |
| `tests/` | Проверки данных, тренажёра и публичной сборки |

## Запуск

Из корня репозитория выполните `python3 -m http.server 8000` и откройте http://localhost:8000/. Статический сервер нужен для загрузки JSON пробников.

Серверная админка запускается по инструкции в [server/README.md](server/README.md). На GitHub Pages доступна статическая версия.

## Правка карточек

Откройте файл нужного задания, например [cards/task-15.js](cards/task-15.js), и найдите числовой `id`. В записи находятся `word`, `answer`, `choices`, `explanation` и при необходимости контекст. `legacyId` сохраняет связь с существующими правками администратора.

Для №15 слово записывается целиком, ответом служит Н или НН. При неоднозначной позиции используется `position` с отсчётом от нуля. Для ударений правильная гласная выделяется прописной буквой в `answer`. В пунктуационных карточках `¦` отмечает позиции выбора, а `answer` содержит индексы верных позиций.

Счётчики и история относятся к текущей тренировке. Очередь перемешивается раундами по содержанию упражнений, повторяющиеся исходные записи объединяются при выборе.

Методика объяснений находится в [EXPLANATION_GUIDELINES.md](EXPLANATION_GUIDELINES.md). Техническое состояние и порядок работы с базой знаний описаны в [knowledge-base/CURRENT_STATE.md](knowledge-base/CURRENT_STATE.md).

## Сборка и проверки

Все команды выполняются из корня репозитория.

```bash
python3 scripts/build_theory.py
node knowledge-base/tools/build.cjs
python3 tests/public-artifact.py
python3 scripts/build_public.py /tmp/russian-public
for script in tests/*.cjs; do node "$script" || exit; done
```

Для публичной сборки укажите новый каталог. Она копирует разрешённые файлы по списку `PUBLIC_FILES` в `server/content/views.py`.

Повторная генерация паронимов выполняется командой `node scripts/build-paronyms.cjs`. Источники и ограничения описаны в [data/paronyms-README.md](data/paronyms-README.md).

Перед изменениями создаётся резервная ветка. Изменения поступают в `main` через pull request с обязательными проверками GitHub.
