# Задание 5 — паронимы

141 карточка из 36 вариантов существующей базы «Дощинский 2027».
В каждой карточке одно предложение, пропуск и полный ряд паронимов
в нужной грамматической форме. Порядок кнопок перемешивается.

Источники:

- Предложения и исправления: `test/bank.js`, `test/doshchinsky-2027/v3.json`–`v36.json`.
- Ряды паронимов: предоставленный пользователем `Slovarik_paronimov.pdf` (список 2022).
- Дополнительные пары, встречающиеся в более новой базе: адресант/адресат,
  авторитарный/авторитетный, ванна/ванная, величие/величина,
  возбуждать/побуждать, земляной/землистый, опасный/опасливый,
  песочный/песчаный, сытый/сытный, яблоневый/яблочный.
- Формат экзамена и проверка различий: https://rustutors.ru/egeteoriya/1138-zadanie-5.html
- Справочник: https://rustutors.ru/egeteoriya/1414-paronimy-egje.html
- Ссылка пользователя на значения: https://3.shkolkovo.online/theory/681?SubjectId=2
  (при подготовке обновления страница не загрузилась).

Пояснения написаны кратко своими словами и перечисляют значения всех кнопок.
Справочник не заменяет полный толковый словарь.

39 контекстов исключены как неоднозначные, близкие по смыслу или повторяющиеся.
Они сохранены в `paronyms-excluded.json`. В частности, не используются
«двойственное/двоякое впечатление», «выбирая/избирая путь»,
«вспышки раздражения/раздражительности», «отрастить/нарастить волосы».
Полное экзаменационное задание с поиском одного неверного слова допускает
контексты, которые не подходят для карточки с одним правильным вариантом.

Ряды из пяти и шести слов сохранены целиком, как в исходном словарике.
Карточки входят в №5 и «Все подряд». Прогресс не сохраняется.
ⓘ появляется только в списке ошибок после неправильного ответа.
На текущей карточке пояснений нет; переход выполняется автоматически.

Проверка: `node tests/paronyms.cjs` (использует `data/paronyms-source.json`).
Восстановление базы: `node build-paronyms.cjs`.
