# База знаний проекта «Русский»

Версия 1.2, 13 ноября 2026 года. Формат — UTF-8 Markdown и JSON. Материал написан как учебная база, а не как копия сайта-источника. Канонический текст находится в `chapters/`; JSON для сайта собирается из него, а не редактируется отдельно.

## Что подготовлено

27 глав по всем заданиям ЕГЭ и 286 правил. В дополнении по оглавлению Рустьюторс добавлены №2, 3, 8, 23–27 и частные случаи для существующих глав. Теория доступна независимо от наличия практики по заданию.

В каждой главе есть предмет проверки, правила с постоянными ID, примеры и особые случаи, порядок применения, разборы, типичные ошибки и источники. Слова «запомни» относятся к словарным случаям и настоящим исключениям; прозрачное правило ими не заменяется.

## Файлы и вход для Codex

- [CURRENT_STATE.md](CURRENT_STATE.md) — устройство сайта, загрузка подсказок, границы текущей работы.
- [chapter-index.json](chapter-index.json) — каталог глав и источников.
- [sources.json](sources.json) — первоисточники, происхождение и статус материалов.
- [GLOSSARY.md](GLOSSARY.md) — общие термины без дублирования по главам.
- `data/stress-words.json` — 219 словоформ текущего проекта с ударной позицией и нужным контекстом.
- `data/paronym-groups.json` — 127 рядов вариантов из 141 существующей карточки паронимов; грамматически разные формы могут давать разные ряды.
- `data/current-inventory.json` — текущие количества карточек по заданиям.

## Сборка без сторонних зависимостей

Из корня репозитория, Node.js:

```bash
node knowledge-base/tools/build.cjs
```

Получатся `knowledge-base/generated/chapters.json`, `rules.json` и единый `KNOWLEDGE_BASE_ALL.md`. Сборка одновременно проверяет состав глав, ID, наличие основных разделов и источников, структуру словников. Это проверка данных, не автоматическая лингвистическая экспертиза.

Обновление снимка существующих словников:

```bash
node knowledge-base/tools/export-project-data.cjs
```

Необязательный экспорт текущих объяснений карточек для сопоставления по ID:

```bash
node knowledge-base/tools/export-project-data.cjs /tmp/russian-project-reference --with-hints
```

Экспорт читает `cards/task-*.js`. Для лингвистической проверки используются нормативные источники и главы базы знаний.

## Актуальность и границы

Официальный архив ФИПИ 2027 скачан и прочитан для проверки структуры заданий и перечня нормативных источников. На странице ФИПИ документы на дату проверки обозначены как проекты; статус и контрольные суммы записаны в `sources.json`. Номера и формат перед будущей публикацией сверить с последней официальной редакцией.

Словник ударений происходит из текущего кода с комментарием «2026», а ряды паронимов — из текущей базы проекта. Они не объявляются полными официальными списками 2027 года и не были заново сплошь сверены с каждым словарём государственного языка. Главы дают полноценную основу по выбранным темам; словарные списки можно расширять отдельно с сохранением источников.

Раздел опубликован в `/theory/`. Текущая структура и команды описаны в [CURRENT_STATE.md](CURRENT_STATE.md). Изменения главы публикуются после повторной сборки `scripts/build_theory.py`.

Раздел сайта — [База знаний](../theory/index.html). После правок глав или словников пересоберите страницу командой `python3 scripts/build_theory.py`.
