# Дощинский 2027: варианты 3–36

884 текстовых задания части 1, по 26 в каждом варианте. Первые два варианта остаются в `../bank.js`; всего 936 заданий. Сочинения не включены.

`vN.json` содержит вопросы, допустимые ответы и два общих текста: `first` для 1–3, `last` для 23–26. Общий текст хранится один раз на вариант. `bank-manifest.js` содержит небольшой индекс, `bank-loader.js` загружает только выбранные варианты и кеширует запросы в пределах открытой страницы.

Источник — предоставленный PDF сборника. Распознавание сверено с текстовыми подборками того же сборника на 100ballnik.com; ключи сверены с исходными таблицами ответов. Неподходящая подборка задания 6 не использовалась: эти 34 задания вычитаны по PDF отдельно. В варианте 11, задании 8 устранена ошибка распознавания ключа: **74158**.

В опубликованных данных нет PDF, фотографий, координат страниц, растровых масок или изображений слов. Поля `prompt` и `passages.*.text` — обычные строки. Выделение задаётся парными `**`, которые интерфейс отображает безопасными текстовыми узлами и элементами `strong`. Служебные номера страниц в `source` оставлены для внутренней сверки; интерфейс показывает только название сборника и ID задания.

Семантические ID `doshchinsky-2027-vN-qM` неизменны. Числовые ID продолжаются с #53 по #936. При импорте на личный хост существующие записи и их ID сохраняются, новые записи не занимают ID уже созданных карточек; повторный импорт не перезаписывает правки администратора.

Вопросы 8 и 22 отображаются двумя текстовыми колонками на большом экране и последовательно на телефоне. В ответах задания 26 допустимые последовательности номеров хранятся целиком: например, `5763` и `6357`.

В книге есть ключи, но нет подробных разборов каждого вопроса. Для новых заданий подробное объяснение оставлено пустым; после завершения интерфейс честно сообщает, что разбор ещё не добавлен.

Проверки: `node tests/exam-bank.cjs`, `python server/manage.py test content`.
