# Руса Лингво — работа с проектом

Репозиторий — `rosenfeldsgit/linguae-Russicae`. Устройство проекта, запуск и проверки описаны в [README.md](README.md).

## Порядок изменений

- Перед изменениями создавать резервную ветку от актуального состояния.
- Изменения оформлять через pull request и дожидаться проверок GitHub.
- Сохранять ID, ответы, учебные форматы и поведение тренировки вне запрошенных изменений.
- При исправлении учебного материала проверять правило по первоисточнику и указывать источник.
- Для новых публичных ресурсов обновлять `public-files.json`.

## Учебные данные

Карточки и их пояснения находятся в `cards/task-*.js`. Методика пояснений описана в [EXPLANATION_GUIDELINES.md](EXPLANATION_GUIDELINES.md).

Перед изменением теории прочитать `knowledge-base/README.md`, `knowledge-base/CURRENT_STATE.md`, `chapter-index.json`, `sources.json` и нужные главы. Канонический текст находится в `knowledge-base/chapters/`. Сохранять постоянные ID правил и условия их применения.

После изменения глав пересобрать теорию и редактор командами из README. Правка теории, карточки и полного задания пробника выполняется в соответствующем источнике данных.
