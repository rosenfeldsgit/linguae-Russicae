# Термины, общие для нескольких заданий

| Термин | Рабочее определение | Где особенно важно |
| --- | --- | --- |
| Морфема | Значимая часть слова: корень, приставка, суффикс, окончание | 9–15 |
| Производящее слово | Слово, от которого непосредственно образовано рассматриваемое | 11, 12, 15 |
| Орфограмма | Место выбора нормативного написания | 9–15 |
| Лексическое значение | Содержание слова в данном употреблении | 1, 5, 6, 13, 14 |
| Синоним | Близкое по значению слово с учётом контекста | 5, 6, 13 |
| Совершенный вид | Действие как целое с ограничением/результативностью; школьный вопрос «что сделать?» | 12, 15 |
| Несовершенный вид | Процесс, повторяемость и другие нецелостные представления действия; «что делать?» | 12, 15 |
| Спряжение | Система изменения глагола по лицам и числам | 12 |
| Причастие | Форма глагола, обозначающая признак по действию | 12, 13, 15, 17 |
| Деепричастие | Форма глагола, обозначающая добавочное действие | 12, 13, 17 |
| Краткое причастие | Краткая форма страдательного причастия, обычно предикативная | 13, 15 |
| Краткое прилагательное | Форма прилагательного, выражающая признак в предикативном употреблении | 13, 15 |
| Зависимое слово | Слово, подчинённое другому по смыслу и грамматической связи | 13, 15, 17 |
| Грамматическая основа | Предикативный центр, в том числе в односоставном предложении | 16–21 |
| Однородные члены | Синтаксически равноправные члены с одной функцией в соответствующем ряду | 16 |
| Придаточная часть | Зависимая предикативная часть СПП | 19, 20 |
| Союзное слово | Местоименное слово, связывающее части и являющееся членом придаточной | 1, 19 |
| Вводное слово | Комментарий говорящего, не входящий в структуру членов предложения | 18 |
| Обращение | Наименование адресата речи | 18 |
| Троп | Переносное/образное употребление слов | 22 |
| Стилистическая фигура | Выразительная организация речевой конструкции | 22 |

Определения даны для школьного применения и не заменяют подробное описание спорных категорий. Например, классификация местоименных слов и особых глагольных парадигм может различаться между грамматическими традициями; в экзаменационной задаче нужен язык актуального учебного и нормативного источника.
