# Ѣ — новый дизайн

Редактируемый макет: https://www.figma.com/design/e8jZCPKl7QCpLgjiBdYvwE

Направление: современный швейцарский учебный плакат — крупная узкая кириллица, строгая сетка, тёплая бумага, кобальтовая печать, оранжевый линейный растр. Интерфейс заданий остаётся спокойным и читаемым. Это самостоятельная композиция, вдохновлённая типографическими плакатами Balmer Hählen.

Все тексты и графика — редактируемые слои. Повторяющиеся кнопки и номера — экземпляры компонентов. Палитра — переменные Figma.

## Рабочая копия

`poster.css` и `poster.js` задают новую тему поверх исходной реализации. `index.html` и `test/index.html` содержат новую шапку; карточки получили плакатную боковую полосу. Сохраняются случайный выбор, проверка, ошибки, пояснения, все 936 заданий пробников, баллы, таймеры и просмотр результата. Данные и алгоритмы не изменены.

Шрифты Roboto, Roboto Condensed и IBM Plex Mono хранятся локально в `assets/fonts`; лицензии OFL включены. При переносе на Django новые ресурсы включены в белый список публичных файлов. Админ-панель на GitHub Pages остаётся заглушкой; экран Figma показывает её будущий стиль.

Текущий production: отдельный репозиторий `ege-russkiy`. Новая версия подготавливается отдельно, под именем `ege-russkiy-new`. Изменения макета после обсуждения должны переноситься в CSS/HTML этой копии.

## Проверки

`node tests/exam-bank.cjs`

`python server/manage.py test content`

Открытие: `index.html` через локальный статический сервер; пробники — `test/`.

Обновление: основной шрифт Roboto (400/500/700/900) хранится локально. Логотип в assets/logo.svg и favicon.svg — контуры, без зависимости от шрифта. Плакатный блок assets/brand-poster.svg использует тот же знак и линейный растр.

Основной шрифт возвращён на Golos: четыре локальных TTF начертания (400/500/700/900), preload обычного начертания и отдельная версия CSS. Начертания содержат кириллицу и Ё. Историческая буква Ѣ отсутствует в Golos, поэтому знак остаётся SVG-контуром.

Знак Ѣ переработан на основе контура Ь из Golos Text Black (включая чашу и просвет), с перекладиной и верхним выносным элементом той же толщины. Это адаптированный SVG, а не буквальный экспорт из Figma: экспорт временно недоступен из-за лимита MCP.
