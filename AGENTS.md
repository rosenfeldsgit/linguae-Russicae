# Проект «Русский» — вход для Codex

Основной репозиторий: rosenfeldsgit/linguae-Russicae. Текущий сайт опубликован в GitHub Pages по пути `/linguae-Russicae/`.

## База знаний и следующий этап

Перед работой над теорией прочитать:

1. `knowledge-base/README.md` — состав, актуальность и команды сборки.
2. `knowledge-base/CODEX_HANDOFF.md` — задание на отдельный раздел сайта.
3. `knowledge-base/CURRENT_STATE.md` — файлы приложения и порядок объяснений.
4. `knowledge-base/chapter-index.json`, `sources.json` и главы нужных заданий.

Канонический учебный текст — `knowledge-base/chapters/`. У правил постоянные ID. Снимки старых карточек и словников не объявлять полными официальными словарями 2027 года. Не терять условия правил при сокращении подсказок.

## Постоянные требования пользователя

- До изменений создавать резервную ветку от актуального состояния.
- Изменения оформлять через pull request; не обходить защиту main.
- Называть и давать первоисточники; исправлять неточные утверждения, а не соглашаться с ними.
- Figma-работы вести в одном существующем файле проекта.
- При новой дизайнерской работе обращаться к Pinterest за референсами и напоминать о выборе последней доступной модели Astra.
- Не менять попутно согласованные учебные форматы, ответы карточек и поведение тренировки.

Этот файл не разрешает автоматически публиковать новые страницы при задаче только на подготовку контента. Реализация раздела «Теория» выполняется по следующему запросу пользователя.
